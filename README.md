# Simple Bash Utils

Реализация базовых текстовых утилит Bash на языке C:

## cat
Утилита для конкатенации и вывода содержимого файлов с поддержкой:
- Чтения нескольких файлов
- Нумерации строк (`-n`)
- Отображения непечатаемых символов (`-v`)
- Поддержки специальных символов (`-e`)
- Поддержки синтаксиса escape sequences (`-E`)
- Поддержки табуляции (`-t`)
- Поддержки скрытых символов (`-T`)

## grep
Утилита для поиска текста по шаблону с возможностями:
- Поиска по регулярным выражениям
- Игнорирования регистра (`-i`)
- Инвертирования поиска (`-v`)
- Подсчета совпадений (`-c`)
- Поддержки специальных символов (`-e`)
- Поддержки синтаксиса escape sequences (`-E`)
- Поддержки табуляции (`-t`)
- Поддержки скрытых символов (`-T`)
